## Phase 4 expansion (v2): 9 architectures, 18 combos (started 2026-07-28)
Motivated by wanting more than 3 classification models for the thesis. Full rationale, architecture selection reasoning, and verified param counts/resolutions in `02_current_status.md`.

- [x] Reviewed the original 3 models' results *and* actual classifier code (not just the results table) — found a real, previously-unnoticed inconsistency: ResNet18 had zero head-level dropout while MobileNetV3-Small/EfficientNet-B0 each had a hardcoded, untuned p=0.2. This directly motivated standardizing dropout as a searched hyperparameter across all 9 architectures, not just the 6 new ones.
- [x] Selected 3 new CNNs — DenseNet121 (dense connectivity), ConvNeXt-Tiny (transformer-era-redesigned pure CNN), RegNetY-400MF (NAS design-space search) — and 3 new transformers by size tier — Swin-Tiny (lightweight, local windowed attention), ViT-B/16 (medium, canonical global attention), ViT-L/16 (heavy, `IMAGENET1K_SWAG_LINEAR_V1` weights specifically, since the default `IMAGENET1K_V1` weights verified weaker than ViT-B/16's). All 6 confirmed available natively in the installed `torchvision 0.28.0` — zero new dependencies.
- [x] Decided (project author confirmed): retrain all 9 architectures, not just the 6 new ones, under one unified v2 protocol so the final comparison table is strictly apples-to-apples — **18 total (architecture, tissue_type) combos**.
- [x] v2 protocol settings confirmed: `MAX_EPOCHS` 30→100, `EARLY_STOPPING_PATIENCE` 5→7 (raised to tolerate dropout=0.5's added val-loss noise), `dropout_rate` added as a 3rd Optuna-tuned categorical hyperparameter (`{0.2, 0.5}`).
- [x] `ARCHITECTURE_REGISTRY` (`trainer_engine.py`) restructured from `name -> build_fn` to `name -> {build_fn, input_size}`, extended to all 9 architectures. Every builder now takes `dropout_rate` and threads it into a `Dropout -> Linear` head — overwriting the pre-existing fixed-p=0.2 module for MobileNetV3-Small/EfficientNet-B0 (rather than stacking a second dropout), inserting a fresh one for the other 7.
- [x] `dataset.py`'s `get_dataloaders()` made resolution-aware (new `image_size` param, default unchanged at 256) — the 6 CNNs stay at 256 (resolution-flexible via pooling, already proven), the 3 transformers use 224 (position-embedding-locked to their pretrained patch grid).
- [x] Structural verification: all 9 architectures × 2 dropout rates build, forward-pass correctly at their registered resolution (output shape `(B, 1)`), and the sampled `dropout_rate` is confirmed actually present in the model's `Dropout` module (not just silently accepted) — zero errors, exit code 0.
- [x] 18 new entry-point scripts generated in a dedicated `classification/v2_scripts/` directory, isolated from the original `classification/scripts/train_*.py` six (which are now retired and must not be re-run as-is — the shared engine changed underneath them, so re-running one under its old un-suffixed `model_name` would silently overwrite the v1 checkpoint/logs). - [x] Local 1-trial/1-epoch dry run, 2026-07-28 — DenseNet121/palpebral (new CNN, 256px) and Swin-T/palpebral (new transformer, 224px), run through the real `run_study()` path with `MAX_EPOCHS` monkey-patched to 1 (temporary, not a code change).
